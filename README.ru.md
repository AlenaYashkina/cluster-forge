# Cluster Forge — распределение фотографий при участии человека

[English README](README.md) · [Запись интерфейса (MP4)](assets/cluster-preview.mp4) · [Постер](assets/cluster-poster.png)

**Задача.** Для подготовки фототехнических отчётов сотни и тысячи кадров нужно распределять по категориям и этапам работ, не теряя контроль над файлами и возможностью исправления ошибок.

**Решение.** Пользователь размечает несколько фотографий; `transformers.CLIPModel` извлекает числовые признаки, система сравнивает их с центроидами категорий и предлагает подходящий класс. Автоматическое распределение выполняется по настраиваемому порогу сходства, сомнительные случаи остаются человеку. Интерфейс React/Vite, сервер FastAPI и журнал действий.

**Мой вклад.** Постановка задачи, логика human-in-the-loop, сценарии ручной сортировки, разработка с AI coding assistants, проверка поведения и исправления. Веса CLIP не дообучаются; показатель сходства — не «процент точности».

**Проверки.** `python -m pip install pytest`, затем `python -m pytest -q tests/test_safe_cluster_names.py tests/test_undo_safety.py`. Тесты включают обход директорий, символические ссылки, отмену и сохранение файлов при совпадении имён.

**Важная безопасность.** API рассчитан только на локальный запуск; необходимо задать `CLUSTER_FORGE_WORKSPACE` с **копиями** фотографий, не публиковать порт сервера. Реальная точность классификации на отдельной проверочной выборке пока не измерена.
